01

Lists

What Is a List?

A list is a way to store many values together in one variable, in a specific order. You create one with square brackets [ ], and separate each value with a comma.

Here, fruits is a single variable, but it holds three separate pieces of text. That's the whole point of a list — one name, many values.

Every value in a list has a position number, called an index. Python starts counting from 0, not 1. You can grab any single value by writing the list's name followed by its index in square brackets. 


fruits = ['apple', 'banana', 'cherry']

print(fruits[0])   # apple
print(fruits[1])   # banana
print(fruits[2])   # cherry
print(fruits[-1])  # cherry (the last item)

Notice that 'apple' is at index 0, not index 1. And -1 is a shortcut Python gives you for "the last item" — handy when you don't know exactly how many items are in the list. 






fruits = ['apple', 'banana', 'cherry']
fruits[1] = 'blueberry'

print(fruits)  # ['apple', 'blueberry', 'cherry']
02

Changing Lists

How Do You Change What's in a List?

Unlike a number or a string, a list can be changed after you create it. To replace one value, point to it by its index and assign a new value, just like you would with a normal variable.

Here, fruits[1] was 'banana'. Setting fruits[1] = 'blueberry' replaces just that one item — the rest of the list stays the same.

You don't have to know an index to add something new. The .append() method adds a value to the end of a list. And len(), a function you've already seen with strings, tells you how many items are in a list. 


fruits = ['apple', 'banana', 'cherry']
fruits.append('date')

print(fruits)        # ['apple', 'banana', 'cherry', 'date']
print(len(fruits))  # 4





fruits = ['apple', 'banana', 'cherry']

for fruit in fruits:
    print(fruit)

# apple
# banana
# cherry
03

Repeating Tasks

How Does a for Loop Work?

A for loop lets you go through a list one item at a time, and run the same code for each one. Here, fruit is a new, temporary variable — on each pass through the loop, it holds the next value from fruits.

Just like if and functions, the code that belongs to the loop is marked with a colon ( : ) and indentation.

Sometimes you want to repeat something a set number of times, without looping over a list at all. The built-in range() function gives you a sequence of numbers to loop through instead. 


for number in range(5):
    print(number)

# 0
# 1
# 2
# 3
# 4

Careful here: range(5) counts five numbers, starting at 0 and stopping right before 5. It never actually reaches the number 5. This matches how list indexes work, which is why range() is so often used with lists. 






count = 1

while count <= 5:
    print(count)
    count += 1

# 1
# 2
# 3
# 4
# 5
04

Looping Until Done

How Does a while Loop Work?

A while loop keeps repeating its code for as long as a condition stays True. Unlike a for loop, you don't decide in advance how many times it runs — that depends on when the condition finally becomes False.

Here, count starts at 1 and goes up by 1 each time, using count += 1 (from Week 2). Once count reaches 6, count <= 5 becomes False, and the loop stops.

Be careful with while loops: if the condition never becomes False, the loop will never stop. This is called an infinite loop. Always make sure something inside the loop is working toward ending it, like count += 1 did above.


A while loop is a great fit when you don't know how many times something needs to repeat — like waiting for a person to type a specific word: 


answer = ''

while answer != 'quit':
    answer = input('Type quit to stop: ')

print('You stopped the loop!')

# Example run:
# Type quit to stop: hello
# Type quit to stop: quit
# You stopped the loop!

answer starts as an empty string, which is not equal to 'quit', so the loop begins. Each time through, it asks the person to type something. As soon as they type 'quit', the condition becomes False and the loop ends. 






def check_grade(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 70:
        return 'C'
    else:
        return 'F'

scores = [95, 82, 67, 74, 58]

for score in scores:
    grade = check_grade(score)
    print(score, '->', grade)

# 95 -> A
# 82 -> B
# 67 -> F
# 74 -> C
# 58 -> F
05

Putting It Together

Combining Lists, Loops & Functions

Here, scores is a list of five test scores. The for loop visits each one, and for every score it calls check_grade() — the same function from Week 4 — to work out the letter grade, then prints the result.

You can also build a brand-new list while you loop. Here, we use an if condition inside the loop to collect only the scores that passed, using .append() to add each one to a new list: 


def check_grade(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 70:
        return 'C'
    else:
        return 'F'

scores = [95, 82, 67, 74, 58]
passing_scores = []

for score in scores:
    grade = check_grade(score)
    if grade != 'F':
        passing_scores.append(score)

print(passing_scores)  # [95, 82, 74]

passing_scores starts as an empty list [ ]. Every time the loop finds a score that isn't an 'F', it adds that score to the end of the list. By the time the loop finishes, passing_scores holds only the scores of 70 or above.

01

Dictionaries

What Is a Dictionary?

A dictionary stores data as labeled pairs. Each pair has a key (the label) and a value (the data). You create one with curly braces { }, writing each pair as key: value, separated by commas.

Think of a real dictionary: you look up a word (the key) to find its meaning (the value). A Python dictionary works the same way — you look things up by name, not by position like you do with a list.

To get a value out of a dictionary, write the dictionary's name followed by the key in square brackets — not the position number you used with lists, but the actual key you gave it. 


student = {'name': 'Maria', 'age': 21, 'major': 'Computer Science'}

print(student['name'])  # Maria
print(student['age'])   # 21

Each key in a dictionary must be unique, but the values can repeat or be any type — text, numbers, even lists. 






student = {'name': 'Maria', 'age': 21}
student['age'] = 22
student['major'] = 'Computer Science'

print(student)  # {'name': 'Maria', 'age': 22, 'major': 'Computer Science'}
02

Changing Dictionaries

How Do You Add or Update Data?

You use the same dict[key] = value pattern for both jobs. If the key already exists, Python updates its value. If the key is new, Python adds it as a brand new pair.

Here, 'age' already existed, so it gets updated to 22. 'major' did not exist yet, so it gets added as a new key.

Before looking up a key, it's often useful to check whether it exists at all. The in keyword (from Week 3) checks a dictionary too, and gives you back True or False. 


student = {'name': 'Maria', 'age': 22}

print('name' in student)   # True
print('email' in student)  # False

This matters because looking up a key that doesn't exist, like student['email'], doesn't just give you nothing back — it stops your program with an error. You'll learn how to handle that safely later in this lesson. 






student = {'name': 'Maria', 'age': 22, 'major': 'Computer Science'}

for key in student:
    print(key)

# name
# age
# major
03

Looping Dictionaries

How Do You Loop Through a Dictionary?

You can use a for loop (from Week 5) on a dictionary too. By default, it hands you each key, one at a time — not the value.

Most of the time, you want both the key and its value together. The .items() method gives you exactly that, so you can grab both in one loop. 


student = {'name': 'Maria', 'age': 22, 'major': 'Computer Science'}

for key, value in student.items():
    print(key, ':', value)

# name : Maria
# age : 22
# major : Computer Science

Notice there are now two loop variables, key and value, instead of one. On each pass, Python fills them in with the next pair from the dictionary. 






try:
    number = int('abc')
    print(number)
except ValueError:
    print('That is not a valid number.')

# That is not a valid number.
04

Handling Errors

What Do try and except Do?

Sometimes code fails while it's running — like trying to turn the text 'abc' into a number. Python calls this an error. Without any help, an error stops your whole program immediately.

try lets you attempt some risky code. If it fails, Python jumps straight to except instead of crashing, and your program keeps running.

Python has different names for different kinds of errors, so you can catch the exact one you expect. ValueError happens when a value is the wrong "shape" for what you're asking — like text that isn't really a number. This is especially useful with input(), since you can never fully trust what a person types. 


try:
    age = int(input('Enter your age: '))
    print('Next year you will be', age + 1)
except ValueError:
    print('Please enter a whole number.')

# Example run:
# Enter your age: twenty
# Please enter a whole number.

Here, the person typed 'twenty' instead of a number. int() can't turn that into a number, so it raises a ValueError. Instead of crashing, the except block catches it and shows a friendly message. 






prices = {'apple': 1.50, 'banana': 0.75, 'cherry': 3.00}

item = input('Which item do you want the price for? ')

try:
    print('Price:', prices[item])
except KeyError:
    print('Sorry, that item is not in stock.')

# Example run:
# Which item do you want the price for? banana
# Price: 0.75
05

Putting It Together

Combining Dictionaries & try/except

This program looks up a price by name in the prices dictionary. If the item the person typed isn't a key in the dictionary, Python would normally raise a KeyError — but the try/except block catches it and shows a friendly message instead of crashing.

Let's combine everything from this course so far: a list of items to check (Week 5), a for loop to go through them (Week 5), a dictionary to look up prices (this lesson), and try/except to handle any item that isn't in stock (this lesson): 


prices = {'apple': 1.50, 'banana': 0.75, 'cherry': 3.00}
shopping_list = ['apple', 'cherry', 'mango']

for item in shopping_list:
    try:
        print(item, ':', prices[item])
    except KeyError:
        print(item, ': not in stock')

# apple : 1.5
# cherry : 3.0
# mango : not in stock

The loop checks each item in shopping_list one at a time. 'apple' and 'cherry' are both keys in prices, so their prices print normally. 'mango' is not a key in prices, so it would normally crash the program — instead, except catches it, and the loop keeps going.

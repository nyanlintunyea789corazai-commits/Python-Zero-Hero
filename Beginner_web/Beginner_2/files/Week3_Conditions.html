01

Decisions

What Is an if Statement?

An if statement lets your program make a choice. Think of it like a simple rule: "if this is true, do this." When the condition is True, Python runs the code inside the rule. When the condition is False, Python skips that code completely.

Every if line ends with a colon ( : ). The lines that belong inside the if must be indented — moved in a few spaces from the left. This indenting is how Python knows which lines are "inside" the rule.

If the condition is False, Python skips every line inside the if block. It does not run those lines at all. Then it moves on to whatever comes next in your program — the lines that are not indented. 


age = 15

if age >= 18:
    print('You are an adult.')

print('This line always runs.')  # This line always runs.

In this example, age is 15. Is 15 greater than or equal to 18? No — that's False. So the indented print('You are an adult.') line gets skipped. But the last line is not indented, so it always runs, no matter what age is. 






x = 10
y = 3

print(x == y)   # False
print(x != y)   # True
print(x > y)    # True
print(x < y)    # False
print(x >= 10)  # True
print(x <= 3)   # False
02

Building Conditions

What Are Comparison Operators?

A condition is just a question with a yes-or-no answer — Python calls the answers True and False. To ask these questions, you use comparison operators: == (equal to), != (not equal to), > (greater than), < (less than), >= (greater than or equal to), and <= (less than or equal to).

Be careful not to mix up = and ==. One equals sign ( = ) means "store this value" — like x = 10, which stores 10 in x. Two equals signs ( == ) mean "is this equal to that?" — it asks a question instead of storing anything.

Sometimes you need to check more than one thing at once. Logical operators let you combine conditions: and means both conditions must be true, or means at least one must be true, and not simply flips true to false (or false to true). 


age = 25
has_id = True
day = 'Saturday'
is_raining = False

if age >= 18 and has_id:
    print('You may enter.')          # You may enter.

if day == 'Saturday' or day == 'Sunday':
    print('It is the weekend.')      # It is the weekend.

if not is_raining:
    print('Go outside!')             # Go outside!





score = 72

if score >= 90:
    print('Grade: A')
elif score >= 80:
    print('Grade: B')
elif score >= 70:
    print('Grade: C')  # Grade: C
03

More Conditions

How Do You Check More Than One Condition?

elif is short for "else if". It lets you check another condition when the first if was false. Python checks each condition from top to bottom. As soon as it finds one that is true, it runs that block of code and skips everything else below it.

You can add as many elif lines as you need. But what happens if none of them are true? Then none of the code inside if or elif runs — Python just moves on to the next line in your program. 


score = 50

if score >= 90:
    print('Grade: A')
elif score >= 80:
    print('Grade: B')
elif score >= 70:
    print('Grade: C')

print('Done checking your grade.')  # Done checking your grade.

Here, score is 50. It doesn't match any of the three conditions, so none of the print lines inside the if / elif run. That's a problem if you always want something to happen. This is exactly what else is for. 






score = 50

if score >= 90:
    print('Grade: A')
elif score >= 80:
    print('Grade: B')
elif score >= 70:
    print('Grade: C')
else:
    print('Grade: F')  # Grade: F
04

The Catch-All

What Does else Do?

else does not check a condition. It is simply a backup plan: if none of the if or elif conditions above it were true, the code inside else runs instead. Adding else means your program always has something to do, no matter what.

You can use if by itself, if with else, if with one or more elif, or all three together. No matter which you use, only one block of code ever runs. As soon as Python finds a true condition, it runs that block and ignores the rest — even if a condition further down would also be true. 


temperature = 85

if temperature > 50:
    print('It is warm.')   # It is warm.
elif temperature > 80:
    print('It is hot!')
else:
    print('It is cold.')

Here, temperature is 85. The first condition, temperature > 50, is already true, so Python runs "It is warm." and stops right there. It never even looks at the elif line, even though 85 is also greater than 80. This shows why the order of your conditions matters. 






name = input('What is your name? ')

if name == 'Alex':
    print('Hey, I know you!')
else:
    print('Nice to meet you, ' + name + '!')

# Example run:
# What is your name? Alex
# Hey, I know you!
05

Real Decisions

How Do You Use What the User Types?

The built-in input() function stops your program and waits. It waits for the person using your program to type something and press Enter. Then it gives you back whatever they typed. Important: input() always gives you a string of text, even if the person types numbers.

In this example, we are comparing text to text (name == 'Alex'), so we can compare it right away with == — no extra steps needed.

Numbers need one extra step. Since input() always gives you text, you can't compare it to a number right away — it won't work the way you expect. First, you need to turn that text into a real number, using int() or float(). You saw these same functions back in the Numbers lesson. 


age_input = input('How old are you? ')
age = int(age_input)

if age >= 18:
    print('You may enter.')
else:
    print('Sorry, you must be 18 or older.')

# Example run:
# How old are you? 20
# You may enter.

Now let's put it all together. Here's a grade calculator: it asks the user to type a score, turns that text into a number, and then uses the same if / elif / else steps from earlier to decide the grade: 


score_input = input('Enter your test score: ')
score = int(score_input)

if score >= 90:
    print('Grade: A')
elif score >= 80:
    print('Grade: B')
elif score >= 70:
    print('Grade: C')
else:
    print('Grade: F')

# Example run:
# Enter your test score: 85
# Grade: B

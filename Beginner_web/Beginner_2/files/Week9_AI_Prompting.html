01

Prompts

How Do You Write a Good Prompt?

An AI tool like ChatGPT or Gemini is a chatbot: you type a message in plain English, and it types an answer back. The message you type is called a prompt. Both tools have free versions. You usually sign in with an account, and free versions have usage limits that can change — if you hit a limit, wait a while and try again.

A good prompt has three parts. The first sentence above (purple) is the context: who you are. The second (green) is the task: what you want. The third (yellow) is the details: how you want the answer.

The AI can't see your screen, and it doesn't know what you already understand. It only knows what you type. That's why a short, vague prompt gives a vague answer. 


Weak prompt:
my code doesn't work

Better prompt:
I'm a beginner learning Python. My program should print a list of fruits, but I get an error. I will paste my code and the error message below. Can you explain what went wrong in simple words?

The weak prompt doesn't say which language, which code, or what went wrong. The better prompt gives all three parts. You can also keep asking follow-up questions in the same chat — the AI remembers what you said earlier in that conversation. 






I'm a beginner learning Python.
What is the difference between a list and a dictionary?
Give me one everyday comparison for each, and show a short example of both.
02

Learning

How Do You Ask Questions to Learn?

Think of an AI tool as a patient tutor that is available any time. You can ask the same thing ten different ways, and it never gets tired of you.

Here are useful things to ask for: an everyday comparison, a short example, the difference between two ideas, or the same answer in simpler words.

One of the best ways to learn is to ask the AI to quiz you. Asking for one question at a time makes you think and answer for yourself before you see the next one. 


I'm a beginner who just learned for loops and while loops in Python. Quiz me with 3 short questions. Ask one question at a time, wait for my answer, and then tell me if I was right before moving on.

And when part of an answer doesn't make sense, don't just move on. Copy the confusing part and ask again: 


I don't understand this part: [paste the part you don't understand here]. Please explain it again using simpler words and a different example.

The words in square brackets are a placeholder — replace them with your own text before you send the prompt. 






# This code has a bug (on purpose!)
fruits = ['apple', 'banana', 'cherry']

print(fruits[3])  # IndexError: list index out of range
03

Fixing Errors

How Can AI Help You Fix Code Errors?

When Python can't run a line, it stops and prints an error message. Read the last line of that message first. It tells you the name of the error and the reason. Here, that's IndexError: list index out of range.

That last line, plus your code, is exactly what an AI tool needs. A good fix-it prompt has three things: your code, the error message, and what you expected to happen.

Here is a fix-it prompt for the bug above. It includes the context, the code, the error, and a request for a simple explanation: 


I'm a beginner learning Python. I want to print the last fruit in my list, but I get an error.

My code:
fruits = ['apple', 'banana', 'cherry']
print(fruits[3])

The error:
IndexError: list index out of range

What does this error mean, and how do I fix it? Please explain in simple words.

A good answer will explain that the list has three items, and Python counts from 0 (Week 5). So the valid positions are 0, 1, and 2 — there is no position 3. Here is the fixed code: 


fruits = ['apple', 'banana', 'cherry']

print(fruits[2])   # cherry
print(fruits[-1])  # cherry

Don't stop once you have a fix. Run it yourself to check that it works, and ask the AI why the error happened, so you can spot it yourself next time.



Here is a second common error, from Week 3. The person types 20, but input() gives back text, and Python can't compare text with a number: 


# This code has a bug (on purpose!)
age = input('How old are you? ')

if age >= 18:
    print('You may enter.')

# Example run:
# How old are you? 20
# TypeError: '>=' not supported between instances of 'str' and 'int'

You would follow the same steps: paste your code and that last error line into a prompt. The AI should tell you to turn the text into a number with int(). Here is the fixed version: 


age = int(input('How old are you? '))

if age >= 18:
    print('You may enter.')

# Example run:
# How old are you? 20
# You may enter.

Capstone Launch

How Do You Plan a Simple Project?

Your capstone is a small project that puts together what you have learned. Planning first helps you avoid feeling lost. AI is very good at taking a big idea and breaking it into small steps.

Pick a small idea, like a contact book, a quiz game, a to-do list, or an expense tracker. Tell the AI what you already know, and ask for a plan — not the finished code. That way, you still do the building and the learning.

A plan you get back might look something like this. Yours may look different, and that's fine. Notice that every step is small, and each one uses something you already learned: 


Example plan (yours may look different):

Step 1: Create a dictionary to store contacts (name and phone number). Week 6
Step 2: Write an add_contact() function. Week 4
Step 3: Write a show_contacts() function that loops through all contacts. Week 5
Step 4: Let the user search for a name, and use try/except when the name is not found. Week 6
Step 5: Add a menu with a while loop and input() so the user can choose what to do. Weeks 3 and 5
Step 6 (optional): Turn each contact into a Contact class. Week 7

Now start tiny. Build Steps 1 to 3, run them, and check that they work before you go on: 


contacts = {}

def add_contact(name, phone):
    contacts[name] = phone

def show_contacts():
    for name, phone in contacts.items():
        print(name, ':', phone)

add_contact('Maria', '555-0100')
add_contact('Sam', '555-0101')
show_contacts()

# Maria : 555-0100
# Sam : 555-0101

Build one step, run it, test it, and only then move to the next one. If you get stuck on a step, ask the AI about just that step — not the whole project. 






I'm a beginner learning Python. I'm working on step 4 of my contact book plan: searching for a name. Here is my code:

[paste your code here]

I'm stuck. Please give me a hint only, not the full answer, and explain the idea in simple words.
05

Using AI Wisely

How Do You Use AI Wisely?

Try first, then ask. Struggling with a problem for a while is how your brain learns. When you're stuck, ask for a hint, like in the prompt above, instead of the full answer.

Never share private information. Don't paste passwords, secret keys, ID numbers, or home addresses into an AI tool. If your code contains any, remove them or replace them with fake values first.

AI can be wrong — even when it sounds sure. Always run the code yourself and check that the output is what you expected. If you're not sure about something, check the official Python documentation at docs.python.org.


Understand before you use. Never put code in your project if you can't explain it. If you don't understand some code, ask: 


Explain this code line by line, as if I'm a complete beginner: [paste the code here]

Follow your course rules. Check what your teacher or course allows for AI use on graded work, and be honest about where you used it.



Your capstone launch checklist:


1. Pick one small project idea you're excited about.

2. Write a planning prompt with context, task, and details — and ask for steps, not code.

3. Build Step 1. Run it and test it.

4. Repeat for each step. When you get an error, use a fix-it prompt with your code and the error message.

5. When you're stuck, ask for a hint, not the answer.

6. Finish by testing everything — and make sure you can explain every line of your project.

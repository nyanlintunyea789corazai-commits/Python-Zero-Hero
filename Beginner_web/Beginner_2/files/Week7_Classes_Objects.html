01

Classes

What Is a Class?

A class is a blueprint for creating things. It doesn't hold any real data on its own — it just describes what every thing made from it will look like.

Think of a cookie cutter shaped like a dog. The cutter itself isn't a cookie — but you can use it to stamp out as many dog-shaped cookies as you like. A class works the same way: you define it once with the class keyword, then use it to create real objects.

Here, class Dog: creates the blueprint. Writing pass just means "there's nothing here yet" — it's a placeholder so the class has a body. Then Dog() uses that blueprint to create an actual object, which we save in the variable my_dog.


Notice the class name, Dog, starts with a capital letter. That's a Python convention — not a rule, but nearly every Python programmer follows it, so class names are easy to spot at a glance. 






class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

my_dog = Dog('Rex', 'Labrador')

print(my_dog.name)   # Rex
print(my_dog.breed)  # Labrador
02

The Constructor

What Does __init__ Do?

__init__ is a special method that runs automatically every time you create a new object from a class. It's the perfect place to set up the object's starting data, called its attributes.

Inside, self.name = name stores the value on the object itself, as an attribute. Once it's stored, you can read it anytime with dot notation, like my_dog.name.

self always refers to "this particular object" — the one being created or used right now. Every method inside a class starts with self as its first parameter, but you never type it in yourself when calling the method. Python fills it in automatically.


That's why __init__(self, name, breed) takes three parameters, but Dog('Rex', 'Labrador') is only called with two values. Python quietly passes the new object in as self — you only supply name and breed. 






class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

dog1 = Dog('Rex', 'Labrador')
dog2 = Dog('Bella', 'Poodle')

print(dog1.name)  # Rex
print(dog2.name)  # Bella
03

One Blueprint, Many Objects

How Do You Create Multiple Objects?

Every time you call Dog(...), Python builds a brand new object with its own separate set of attributes. dog1 and dog2 are two completely different objects, even though they came from the exact same class.

You can also change an attribute after the object already exists, using dot notation and = — just like updating a value in a dictionary. 


class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

dog1 = Dog('Rex', 'Labrador')
dog2 = Dog('Bella', 'Poodle')

dog1.name = 'Max'

print(dog1.name)  # Max
print(dog2.name)  # Bella

Changing dog1.name only affects dog1. dog2 is a separate object with its own name attribute, so it's completely unaffected. 






class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        print(self.name + ' says Woof!')

my_dog = Dog('Rex', 'Labrador')
my_dog.bark()  # Rex says Woof!
04

Basic Actions

How Do You Give an Object Actions?

A method is simply a function defined inside a class. Like __init__, every method automatically receives self as its first parameter, which is how it reaches the object's own attributes — here, self.name.

You call a method the same way you access an attribute, with a dot, followed by parentheses: my_dog.bark().

A method can also change an object's attributes, not just read them. Here, have_birthday() updates self.age using += (from Week 2), and uses str() (from Week 1) to turn that number into text so it can be joined into a sentence. 


class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def have_birthday(self):
        self.age += 1
        print(self.name + ' is now ' + str(self.age) + ' years old.')

my_dog = Dog('Rex', 3)
my_dog.have_birthday()  # Rex is now 4 years old.

Each time you call my_dog.have_birthday(), self.age permanently increases by one on that object — the change sticks around for as long as the object exists. 






class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        print(self.name + ' says Woof!')

dogs = [Dog('Rex', 'Labrador'), Dog('Bella', 'Poodle'), Dog('Max', 'Beagle')]

for dog in dogs:
    dog.bark()

# Rex says Woof!
# Bella says Woof!
# Max says Woof!
05

Putting It Together

Combining Classes with Lists & Loops

Objects can live inside a list, just like numbers or text (from Week 5). Here, dogs holds three separate Dog objects. The for loop visits each one and calls .bark() on it, so every dog gets to bark in turn.

Let's combine attributes, a method, a list, and a loop into one final example — a class with three attributes and a method that describes the object using all of them: 


class Dog:
    def __init__(self, name, breed, age):
        self.name = name
        self.breed = breed
        self.age = age

    def describe(self):
        print(self.name + ' is a ' + str(self.age) + '-year-old ' + self.breed + '.')

dogs = [Dog('Rex', 'Labrador', 3), Dog('Bella', 'Poodle', 5)]

for dog in dogs:
    dog.describe()

# Rex is a 3-year-old Labrador.
# Bella is a 5-year-old Poodle.

Each Dog object keeps track of its own name, breed, and age. The loop doesn't need to know any of those details in advance — it just asks each object to describe itself, and every object knows how.

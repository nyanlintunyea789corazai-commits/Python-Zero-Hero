01

Inheritance

What Is Inheritance?

Inheritance lets one class reuse the code of another class. The class you take code from is called the parent class. The new class is called the child class. The child gets everything the parent has — its attributes and its methods — without you writing them again.

To make a child class, write the parent's name in parentheses after the child's name: class Dog(Animal):. The Dog class here is completely empty (pass, from Week 7), yet it can still use __init__ and eat() from Animal.

A dog is an animal, and so is a cat. Every animal has a name and can eat. So instead of writing that code again for each kind of animal, you write it once in Animal, and let every child class inherit it. 


class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(self.name + ' is eating.')

class Dog(Animal):
    pass

class Cat(Animal):
    pass

dog = Dog('Rex')
cat = Cat('Luna')

dog.eat()  # Rex is eating.
cat.eat()  # Luna is eating.

This is the same idea as functions in Week 4 — write the code one time, then use it again and again — but now it works for whole classes. 






class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name + ' makes a sound.')

class Dog(Animal):
    def speak(self):
        print(self.name + ' says Woof!')

class Cat(Animal):
    def speak(self):
        print(self.name + ' says Meow!')

animal = Animal('Generic')
dog = Dog('Rex')
cat = Cat('Luna')

animal.speak()  # Generic makes a sound.
dog.speak()     # Rex says Woof!
cat.speak()     # Luna says Meow!
02

Changing What You Inherit

How Do You Override a Method?

Sometimes a child class needs to do something differently from its parent. If you write a method in the child class with the same name as a method in the parent, Python uses the child's version. This is called overriding.

When you call dog.speak(), Python looks in Dog first. It finds speak() there, so it stops looking and runs that one. The plain Animal object has no child version, so it uses the parent's.

A child only needs to override what it wants to change. Everything else is still inherited. Here, Cat overrides speak(), but eat() still comes from Animal. 


class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name + ' makes a sound.')

    def eat(self):
        print(self.name + ' is eating.')

class Cat(Animal):
    def speak(self):
        print(self.name + ' says Meow!')

cat = Cat('Luna')

cat.speak()  # Luna says Meow!
cat.eat()    # Luna is eating.





class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

my_dog = Dog('Rex', 'Labrador')

print(my_dog.name)   # Rex
print(my_dog.breed)  # Labrador
03

Adding New Attributes

What Does super() Do?

What if a child class needs an extra attribute, like breed? Then it needs its own __init__. But a child's __init__ replaces the parent's, just like overriding — so the parent's __init__ no longer runs by itself.

super() gives you a way to reach the parent class. Writing super().__init__(name) runs the parent's __init__, so you don't have to repeat self.name = name.

Now every Dog has both a name (set by the parent) and a breed (set by the child). Notice you don't type self inside super().__init__(name) — Python passes it for you, just like it does everywhere else. 


class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

    def describe(self):
        print(self.name + ' is a ' + self.breed + '.')

my_dog = Dog('Rex', 'Labrador')
my_dog.describe()  # Rex is a Labrador.





class Dog:
    def __init__(self, name):
        self.name = name

class Owner:
    def __init__(self, name, dog):
        self.name = name
        self.dog = dog

    def introduce(self):
        print(self.name + ' has a dog named ' + self.dog.name + '.')

rex = Dog('Rex')
maria = Owner('Maria', rex)

maria.introduce()  # Maria has a dog named Rex.
04

Objects Inside Objects

How Do You Combine Classes?

Inheritance describes an "is-a" link: a Dog is an Animal. But sometimes two classes have a "has-a" link instead: an Owner has a Dog. In that case, you don't inherit. You store one object inside the other, as an attribute.

Here, rex is a Dog object. We pass it into Owner, which saves it as self.dog. Later, self.dog.name reaches through the owner to the dog's own name.

An object can also hold a whole list of other objects (Week 5). This Shelter starts with an empty list of animals. Its add() method appends an animal, and list_animals() loops through them all. 


class Animal:
    def __init__(self, name):
        self.name = name

class Shelter:
    def __init__(self):
        self.animals = []

    def add(self, animal):
        self.animals.append(animal)

    def list_animals(self):
        for animal in self.animals:
            print(animal.name)

shelter = Shelter()
shelter.add(Animal('Rex'))
shelter.add(Animal('Luna'))

shelter.list_animals()

# Rex
# Luna

Notice that Shelter has no need for parameters in its __init__ other than self. It just creates an empty list to start with, and animals are added later. 






class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name + ' makes a sound.')

class Dog(Animal):
    def speak(self):
        print(self.name + ' says Woof!')

class Cat(Animal):
    def speak(self):
        print(self.name + ' says Meow!')

class Shelter:
    def __init__(self):
        self.animals = []

    def add(self, animal):
        self.animals.append(animal)

    def all_speak(self):
        for animal in self.animals:
            animal.speak()

shelter = Shelter()
shelter.add(Dog('Rex'))
shelter.add(Cat('Luna'))
shelter.add(Animal('Mystery'))

shelter.all_speak()

# Rex says Woof!
# Luna says Meow!
# Mystery makes a sound.
05

Putting It Together

Combining Inheritance & Classes

This program uses both ideas at once. Dog and Cat inherit from Animal and override speak(). The Shelter holds all of them in one list.

Look at all_speak(): the loop just says animal.speak() for every animal. It doesn't check what kind of animal it is. Each object automatically uses its own version of speak(). That is what makes the system flexible — you can add a new kind of animal later without changing the Shelter at all.

Let's add one more layer: a parent with two attributes, a child that uses super() to add a third, and a describe() method that the child overrides. Cat doesn't override anything, so it just inherits the parent's version. 


class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def describe(self):
        print(self.name + ' is ' + str(self.age) + ' years old.')

class Dog(Animal):
    def __init__(self, name, age, breed):
        super().__init__(name, age)
        self.breed = breed

    def describe(self):
        print(self.name + ' is a ' + str(self.age) + '-year-old ' + self.breed + '.')

class Cat(Animal):
    pass

pets = [Dog('Rex', 3, 'Labrador'), Cat('Luna', 5)]

for pet in pets:
    pet.describe()

# Rex is a 3-year-old Labrador.
# Luna is 5 years old.

The same loop and the same pet.describe() call give two different results. Rex is a Dog, so Python uses the child's describe(). Luna is a Cat with no version of her own, so Python falls back to the parent's.

Numbers

How Do You Work With Integers and Floats?

Integers and floats are the primary numeric data types in Python. With them, you can store numeric data and perform mathematical operations.

Integers are whole numbers without decimal points, either positive or negative. You can check a variable's type with the built-in type() function, as shown here.

Floats are positive or negative numbers with decimal points, like 3.14, -0.5, or 0.0. 


my_float_1 = -12.0
my_float_2 = 4.9

print(type(my_float_1))  # <class 'float'>
print(type(my_float_2))  # <class 'float'>





my_int_1 = 56
my_int_2 = 12

print('Addition:', my_int_1 + my_int_2)     # 68
print('Subtraction:', my_int_1 - my_int_2)  # 44
02

Arithmetic Operations

How Do Arithmetic Operations Work?

Python supports all the standard arithmetic operators. Addition uses + and subtraction uses -, and they work the same way with integers as they do with floats.

Multiplication uses * and division uses /. Division in Python always returns a float, even when both numbers are integers. 


my_int_1 = 56
my_int_2 = 12

print('Multiplication:', my_int_1 * my_int_2)  # 672
print('Division:', my_int_1 / my_int_2)        # 4.666666666666667


The same four operators work exactly the same way with floats: 


my_float_1 = 5.4
my_float_2 = 12.0

print('Addition:', my_float_1 + my_float_2)        # 17.4
print('Subtraction:', my_float_2 - my_float_1)     # 6.6
print('Multiplication:', my_float_2 * my_float_1)  # 64.80000000000001
print('Division:', my_float_2 / my_float_1)        # 2.222222222222222


If you add an integer and a float, the result is automatically converted to a float. This is true for subtraction, multiplication, and division too — mix an int with a float anywhere, and Python hands back a float. 


my_int = 56
my_float = 5.4

sum_int_and_float = my_int + my_float

print(sum_int_and_float)        # 61.4
print(type(sum_int_and_float))  # <class 'float'>





my_int_1 = 56
my_int_2 = 12
my_float_1 = 5.4
my_float_2 = 12.0

mod_ints = my_int_1 % my_int_2
mod_floats = my_float_2 % my_float_1

print('Integer Modulo:', mod_ints)    # 8
print('Float Modulo:', mod_floats)  # 1.1999999999999993

More Operators

What Do Modulo, Floor Division & Exponents Do?

The modulo operator ( % ) returns the remainder when the value on the left is divided by the value on the right.

Floor division divides two numbers and returns the greatest integer less than or equal to the result. It's done with a double forward slash ( // ). 


my_int_1 = 56
my_int_2 = 12
my_float_1 = 5.4
my_float_2 = 12.0

floor_div_ints = my_int_1 // my_int_2
floor_div_floats = my_float_2 // my_float_1

print('Integer Floor Division:', floor_div_ints)  # 4
print('Float Floor Division:', floor_div_floats)   # 2.0


Exponentiation raises a number to the power of another, done with a double asterisk ( ** ). 


my_int_1 = 56
my_int_2 = 12
my_float_1 = 5.4
my_float_2 = 12.0

exp_ints = my_int_1 ** my_int_2
exp_floats = my_float_1 ** my_float_2

print('Integer Exponentiation:', exp_ints)    # 951166013805414055936
print('Float Exponentiation:', exp_floats)  # 614787626.1765089


You might also notice that operations with floats sometimes produce more decimal digits than expected — the sum 0.1 + 0.2 equals 0.30000000000000004 instead of a clean 0.3. This happens because numbers are stored in binary, and some decimal fractions can't be represented exactly — the same way ⅓ can't be written with a finite number of decimal digits (0.3333...). It leads to small rounding errors. 


print(0.1 + 0.2)  # 0.30000000000000004





my_int_1 = 56
my_float_1 = float(my_int_1)

print(my_float_1)        # 56.0
print(type(my_float_1))  # <class 'float'>

Conversions

How Do You Convert & Round Numbers?

Python provides built-in functions for converting numeric data or strings into integers or floats. The float() function returns a floating-point number constructed from the given number.

The int() function returns an integer constructed from the given number — it doesn't round, it simply drops everything after the decimal point. 


my_float = 12.92563
my_int = int(my_float)

print(my_int)        # 12
print(type(my_int))  # <class 'int'>


You can use the same functions to convert a string into either a float or an integer: 


my_str_int = '45'
my_str_float = '7.8'

converted_int = int(my_str_int)
converted_float = float(my_str_float)

print(converted_int, type(converted_int))      # 45 <class 'int'>
print(converted_float, type(converted_float))  # 7.8 <class 'float'>


A few other useful built-ins: round() rounds a number to a given number of decimal places (or to the nearest whole number by default), abs() returns the absolute value of a number, and pow() raises a number to a power — optionally with modular exponentiation. 


rounded_int_1 = round(4.798)
rounded_int_2 = round(4.253, 1)

print(rounded_int_1)  # 5
print(rounded_int_2)  # 4.3

absolute_value = abs(-15)
print(absolute_value)  # 15

result_1 = pow(2, 3)     # equivalent to 2 ** 3
result_2 = pow(2, 3, 5)  # (2 ** 3) % 5

print(result_1)  # 8
print(result_2)  # 3





my_var = 10
my_var += 5
print(my_var)  # 15

# the same thing, written out in full:
my_var = 10
my_var = my_var + 5
print(my_var)  # 15

Augmented Assignment

How Do Augmented Assignments Work?

An augmented assignment combines a binary operation with an assignment in one step. It takes a variable, applies an operation to it with another value, and stores the result back into the same variable, following the pattern variable <operator>= value.

Every arithmetic operator has an augmented form. Here they are with subtraction, multiplication, division, floor division, modulo, and exponentiation: 


count = 14
count -= 3
print(count)  # 11

product = 65
product *= 7
print(product)  # 455

price = 100
price /= 4
print(price)  # 25.0

total_pages = 23
total_pages //= 5
print(total_pages)  # 4

bits = 35
bits %= 2
print(bits)  # 1

power = 2
power **= 3
print(power)  # 8


A couple of augmented assignments also work with strings. Addition assignment concatenates, and multiplication assignment repeats: 


greet = 'Hello'
greet += ' World'
print(greet)  # Hello World

greet = 'Hello'
greet *= 3
print(greet)  # HelloHelloHello


Other augmented assignments throw a TypeError when used with strings: 


greet = 'Hello'
greet -= ' World'
print(greet)
# TypeError: unsupported operand type(s) for -=: 'str' and 'str'

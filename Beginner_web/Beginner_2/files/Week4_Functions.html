01

Functions

What Is a Function?

A function is a piece of code that you give a name to, so you can use it again and again. You create it once using the word def. After that, you can run it anytime just by typing its name followed by parentheses ( ).

Just like an if block, a function needs a colon ( : ) and indented lines below it. But here's the important part: writing the function does not run it. Python only runs the code inside when you actually call the function by its name.

This is what makes functions so useful. You write the code one time. Then you can use it again and again, anywhere in your program, without typing it out every time. 


def greet():
    print('Hello there!')

greet()  # Hello there!
greet()  # Hello there!

Every time you call greet(), Python runs those same two lines again from the top. 






def greet(name):
    print('Hello, ' + name + '!')

greet('Maria')  # Hello, Maria!
greet('Sam')    # Hello, Sam!
02

Passing Inputs

How Do You Pass Inputs with Parameters?

A parameter is like an empty box inside the function's parentheses, waiting for a value. When you call the function, you put a real value into that box — this value is called an argument. Python uses that value only while the function is running.

A function can have more than one parameter — just separate them with commas. Python fills them in order: the first value you give becomes the first parameter, the second value becomes the second parameter, and so on. 


def add(a, b):
    print(a + b)

add(3, 4)   # 7
add(10, 5)  # 15





def greet(name, greeting='Hello'):
    print(greeting + ', ' + name + '!')

greet('Maria')         # Hello, Maria!
greet('Sam', 'Hey')    # Hey, Sam!
03

Optional Inputs

What Are Default Parameter Values?

Writing greeting='Hello' gives that parameter a starting value, called a default value. If you don't give your own value when calling the function, Python automatically uses 'Hello' instead. This makes that parameter optional — you can skip it if you want.

You can also call a function by writing name=value, like greeting='Yo'. These are called keyword arguments. You can write them in any order you like, because Python matches them by name, not by position. This makes your code easier to read, especially when a function has several parameters. 


def greet(name, greeting='Hello'):
    print(greeting + ', ' + name + '!')

greet(name='Alex', greeting='Yo')  # Yo, Alex!
greet(greeting='Yo', name='Alex')  # Yo, Alex! (order doesn't matter here)





def add(a, b):
    return a + b

result = add(3, 4)
print(result)  # 7
04

Sending Results Back

How Do You Return a Value?

print() only shows a value on the screen — it does not give that value back to your program to use later. return is different: it sends the value back to wherever you called the function, so you can save it in a variable and use it again.

Here's a clear example of the difference. If a function has no return line at all, Python gives you back a special empty value called None — even if the function printed something while it was running. 


def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

output_print = add_print(3, 4)    # prints 7 immediately
output_return = add_return(3, 4)  # prints nothing here

print(output_print)   # None
print(output_return)  # 7

A function can also send back more than one value at the same time. Python groups those values together into something called a tuple. You can then split that tuple into separate variables, right when you call the function. 


def get_min_max(numbers):
    return min(numbers), max(numbers)

lowest, highest = get_min_max([4, 9, 1, 7])

print(lowest)   # 1
print(highest)  # 9





def check_grade(score):

        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 70:
        return 'C'
    else:

Putting It Together

Combining Functions, Parameters & Conditions

This function takes score as a parameter. Inside, it uses the same if / elif / else steps from Week 3 to check the score. Instead of printing the grade right away, it returns the grade — so whoever calls the function gets to decide what to do with the result: print it, save it, or use it somewhere else.

Now let's use it with real input() from Week 3. We turn the text the user types into a number, then pass that number into the function as an argument: 


def check_grade(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 70:
        return 'C'
    else:
        return 'F'

score_input = input('Enter your test score: ')
grade = check_grade(int(score_input))
print('Grade:', grade)

# Example run:
# Enter your test score: 85
# Grade: B
